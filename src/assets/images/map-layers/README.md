# 地图视差层素材

此目录用于存放 **成员1** 任务所需的视差背景图片。

## 所需文件

| 文件名 | 尺寸 | 说明 |
|--------|------|------|
| `map-bg-far.png` | 1920×1080 | 远景层（山脉/天空），低对比度，移动幅度最小 |
| `map-bg-mid.png` | 1920×1080 | 中景层（云/树/房子），中等对比度 |
| `map-bg-near.png` | 1920×1080 | 近景层（草地/石头），高对比度，移动幅度最大 |

## 风格要求

- **1930s 手绘卡通风格**（参考 Cuphead 游戏美术）
- 暖色调（棕褐/米色/锈红）
- 边缘可略微模糊以增强景深感
- 推荐使用 **PNG 格式**，带透明通道更佳

## 获取建议

1. **AI 生成**：Midjourney/Leonardo.ai
   - 提示词示例：`1930s cartoon style island landscape layer, hand drawn, sepia tone, Cuphead inspired, seamless, --ar 16:9`

2. **免费素材**：
   - [OpenGameArt.org](https://opengameart.org/)
   - [Itch.io Assets](https://itch.io/game-assets/free)

3. **临时占位**：可先使用纯色/渐变占位，待正式素材到位后替换。
